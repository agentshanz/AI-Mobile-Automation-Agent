
# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x | Yes |
| Older versions | No |

## Reporting a Vulnerability

If you discover a security issue, please report it responsibly instead of publicly disclosing it.

Include the following information:

- Description of the issue
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots (if applicable)

Security-related improvements will be reviewed and addressed in future releases.
